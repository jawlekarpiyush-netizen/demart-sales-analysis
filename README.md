                        D-Mart Retail Business Dashboard

# Project Overview 
This project presents a D-Mart Retail Business Dashboard created using Microsoft Excel. It helps Analyze sales, Revenue, Profit, Discounts, and Payment methods through charts and visualization.

# Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

# Dashboard Features
- Net Revenue Analysis
- Total Sales Analysis
- Total Discount Analysis
- Total Profit Analysis
- Quantity Sold Analysis
- Monthly Sales Analysis
- Sales by Region
- Sales by Payment Mode
- Profit by Category
- Interactive Data Filtering


# Key Insights
- The North region has the highest sales.
- The East region has the lowest sales.
- Monthly sales fluctuate throughout the year.
- Electronics generates the highest profit among the displayed categories.
- Clothing generates the lowest profit among the displayed categories.
- Payments are distributed across Card, Cash, and UPI.

# Conclusion
This dashboard provides an overview of D-Mart's retail business performance. It helps analyze sales trends, compare regional sales, understand category-wise profit, and explore payment methods using Microsoft Excel.
